# ElevenLabs prompt-only TTS screenshot guide

Use this screenshot as a visual example of the difference between broad prompt
control and the project's vowel-level, feature-specific controls.

## Capture the example

1. Open ElevenLabs Text to Speech and select **Eleven v3**.
2. Choose one voice and keep that voice and every generation setting unchanged
   for both examples.
3. Generate the happy version with:

   ```text
   [happy] The wrong shot led the farm.
   ```

4. Generate the sad version with:

   ```text
   [sad] The wrong shot led the farm.
   ```

5. Capture the model selector, selected voice, prompt, visible generation
   settings, and the generated audio result. If both prompts cannot fit in one
   clear screenshot, capture two images using the same crop dimensions.

## Privacy and presentation checklist

- Crop out the account name, email address, avatar, subscription status,
  remaining credits, generation history, and unrelated browser tabs.
- Do not show a private or personally identifiable cloned-voice name.
- Keep the ElevenLabs product name visible so the interface is properly
  attributed.
- Add a caption explaining that the prompt requests a global delivery but does
  not expose which vowels, time spans, or acoustic features changed.
- Do not describe the result as bad or unusable. The intended contrast is
  transparency and experimental control, not general audio quality.

Suggested caption:

> Prompt-based TTS can request a broad emotional delivery, but the generated
> result does not identify which vowel-level pitch, timing, loudness, voicing,
> or phonetic cues produced the change.
